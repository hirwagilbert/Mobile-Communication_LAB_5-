========================================================================
MINI PROJECT 5.2 - MOBILE MALWARE MITIGATION CONTROL MATRIX
========================================================================

[1] SPYWARE  (Data theft / surveillance)
    Case      : Pegasus (NSO Group) - 2016 - 2021 (Pegasus Project, July 2021)
    Vector    : One-click SMS links, network injection, zero-click iMessage
                exploits
    Objective : Full device surveillance: messages, calls, microphone,
                camera, location
    OS-level  : Fast security patching; exploit mitigations (ASLR, pointer
                authentication); BlastDoor sandbox for
                iMessage parsing; iOS Lockdown Mode for
                high-risk users; regular reboot clears non-
                persistent implants
    App store : FINDING: no effective control - delivered by exploits, never
                through an app store, so pre-publication
                vetting and store removal do not apply
    MDM       : Compliance policy enforcing minimum OS/patch level with
                conditional access; mobile threat defense
                (MTD) checking indicators of compromise;
                supervised-device restriction of
                iMessage/FaceTime for high-risk staff
    Source    : Amnesty International Security Lab, 'Forensic Methodology
                Report: How to catch NSO Group's Pegasus'
                (2021); Citizen Lab peer review
    URL       : https://www.amnesty.org/en/latest/research/2021/07/forensic-methodology-report-how-to-catch-nso-groups-pegasus/

[2] BANKING / OVERLAY TROJAN  (Data theft + financial)
    Case      : FluBot (a.k.a. Cabassous) - Late 2020 - May 2022 (Europol takedown, June 2022)
    Vector    : SMS phishing ('missed parcel') links to sideloaded APK;
                worm-like re-sending to the victim's
                contacts
    Objective : Steal banking credentials via overlays; intercept SMS one-
                time passwords
    OS-level  : Per-source 'install unknown apps' permission (Android 8+);
                Restricted Settings block Accessibility for
                sideloaded apps (Android 13+); SMS
                permissions limited to the default SMS app
                role; on-device Play Protect scan
    App store : Limited: app was sideloaded, not published. Post-publication
                style control still applies through Play
                Protect scanning of sideloaded APKs and Safe
                Browsing blocking of the download URLs
    MDM       : Policy blocking unknown sources in the work profile; app
                allow-listing; MTD phishing-link and
                Accessibility-abuse detection; conditional
                access to banking/corporate apps only from
                compliant devices
    Source    : Europol press release (June 2022); NCC Group / Fox-IT,
                'Flubot: the evolution of a notorious
                Android banking malware' (2022)
    URL       : https://www.nccgroup.com/research/flubot-the-evolution-of-a-notorious-android-banking-malware/

[3] RANSOMWARE  (Financial)
    Case      : DoubleLocker (Android/DoubleLocker.A) - Discovered by ESET, October 2017
    Vector    : Fake Adobe Flash Player update on compromised websites;
                abuses Accessibility to make itself the
                default launcher
    Objective : Change the device PIN and encrypt files, then demand a
                Bitcoin ransom
    OS-level  : Android 7+ stops device-admin apps resetting an existing
                PIN; scoped storage (Android 10/11+) limits
                which files an app can encrypt;
                Accessibility consent screens and Restricted
                Settings; sideload gating
    App store : Limited: distributed outside the store. Play Protect on-
                device scanning and Safe Browsing warnings
                are the only store-side controls
    MDM       : Enforced cloud backup of corporate data; remote lock/wipe
                and re-provision; block unknown sources;
                containerisation keeps work files outside
                the personal side the malware runs in
    Source    : ESET / WeLiveSecurity, 'DoubleLocker: Innovative Android
                malware' (2017)
    URL       : https://www.welivesecurity.com/2017/10/13/doublelocker-innovative-android-malware/

[4] PREMIUM-RATE / SMS (TOLL) FRAUD  (Financial)
    Case      : Joker / Bread - Tracked by Google from early 2017; analysis published January 2020
    Vector    : Google Play apps that look legitimate, heavy obfuscation and
                code downloaded at runtime; up to 23 apps
                submitted in one day
    Objective : Sign victims up to premium SMS / WAP (carrier) billing
                services
    OS-level  : SEND_SMS is a runtime (dangerous) permission; premium short-
                code confirmation prompt (Android 4.2+);
                notification-listener access needs a
                separate user grant, limiting OTP theft
    App store : Play SMS/Call Log permission policy (2019) restricting
                SEND_SMS to default SMS apps; static +
                dynamic vetting of submissions; about 1,700
                Bread apps caught before any download; post-
                publication removal
    MDM       : App allow-listing in the work profile; MTD flagging premium-
                SMS behaviour; FINDING: carrier-billing
                blocks on corporate SIMs are an operator
                control, outside MDM reach
    Source    : Google Security Blog, 'PHA Family Highlights: Bread (and
                Friends)' (2020)
    URL       : https://security.googleblog.com/2020/01/pha-family-highlights-bread-and-friends.html

[5] MOBILE BOTNET  (Infrastructure abuse)
    Case      : WireX - August 2017
    Vector    : About 300 apps on Google Play with hidden bot code
    Objective : Application-layer HTTP(S) DDoS attacks from at least 70,000
                IPs in 100+ countries, sometimes linked to
                ransom notes
    OS-level  : Background-execution limits and visible foreground-service
                notifications (Android 8+); per-app data-
                usage visibility. FINDING: INTERNET is a
                normal install-time permission, so the OS
                cannot stop bot traffic
    App store : Pre-publication vetting; post-publication removal of ~300
                apps and Play Protect removal from already-
                infected devices
    MDM       : App allow-listing; per-app VPN / network monitoring for work
                apps; MTD detecting abnormal traffic; non-
                compliant devices blocked from corporate
                resources
    Source    : Joint report by Akamai, Cloudflare, Flashpoint, Google,
                Oracle Dyn, RiskIQ and Team Cymru
                (Cloudflare blog, 28 Aug 2017)
    URL       : https://blog.cloudflare.com/the-wirex-botnet/

Gaps recorded as findings (no plausible / complete control at that layer):
  - Spyware: App store layer
  - Premium-rate / SMS (toll) fraud: MDM layer
  - Mobile botnet: OS layer
